# Contributing to EchoReader AI

We welcome developer contributions to EchoReader AI. Follow these workflows to submit modifications:

---

## 1. Branch Strategy

- Clone the repository.
- Create feature branches targeting `main`:
  ```bash
  git checkout -b feature/your-feature-name
  ```

---

## 2. Coding Standards

- Write TypeScript code in all directories.
- Run quality linters and compiler verification before pushing:
  ```bash
  npm run lint
  npm run build
  ```

---

## 3. Pull Request Standards

- Ensure all CI tests pass.
- Write clear descriptions detailing features or bugfixes.
