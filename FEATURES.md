# EchoReader AI Key Features

This document provides a detailed description of the features available in EchoReader AI.

---

## 1. Document Extraction & OCR
- **Automatic Parsers**: Ingests text files, PDF blocks, Markdown styles, and EPUB books.
- **Optical Character Recognition**: Built-in Tesseract.js engine extracts readable layout text from PNG/JPG scanned pages.

---

## 2. Interactive Natural Playback
- **Sentence highlights**: Spans change backgrounds to active gold/emerald gradients as speech plays.
- **Auto-Scroll**: Automatic viewport sliding centers the current reading section.
- **Speed & Voice Control**: Select speech speed options, genders, accents, and providers (Azure, ElevenLabs, OpenAI).

---

## 3. RAG Intelligence
- **AI QA Chat**: Converse with the document using Gemini API, OpenAI GPT, or local Ollama LLMs.
- **Quick summarizations**: Extract page findings and document scopes instantly.
