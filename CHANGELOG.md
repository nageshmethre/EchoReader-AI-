## [1.0.0] - 2026-08-05

### Added
- Created base workspaces monorepo structure.
- Developed Fastify REST API server.
- Built Next.js web application interface with responsive design.
- Implemented Electron desktop wrapper supporting offline databases and shortcuts.
- Added multi-provider TTS engines (Azure, ElevenLabs, OpenAI) and local Speech Synthesis hooks.
- Configured PostgreSQL Prisma schemas, seed files, and docker-compose templates.
- Developed continuous integration workflows.
